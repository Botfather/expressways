# Governance

Expressways currently uses a maintainer-led governance model.

Maintainers review contributions, make release decisions, manage security disclosures, and protect the system invariants documented in `AGENTS.md` and the security baseline. Routine changes may be merged after one maintainer review. Protocol compatibility, security-boundary, persistence-format, licensing, or major scope changes should receive explicit maintainer approval and, when durable, an ADR.

There is no guaranteed roadmap or support SLA. Project direction is communicated through merged ADRs, issues, pull requests, and release notes. As the contributor base grows, this document should be updated with named roles, nomination/removal rules, and a conflict-resolution process.
