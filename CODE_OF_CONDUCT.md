# Code of Conduct

## Our Standard

We are committed to a respectful, inclusive, and harassment-free community. Be constructive, assume good faith while evaluating technical claims critically, respect differing experience levels, and focus feedback on ideas and behavior rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sustained disruption, deliberate exposure of private information, sexualized conduct, and retaliation against good-faith reporters.

## Enforcement

Report conduct concerns privately to a repository maintainer through their public GitHub profile. Do not use public issues to disclose sensitive personal information. Maintainers may remove content, restrict participation, or ban contributors when necessary to protect the community. Enforcement decisions should be proportionate, documented privately, and avoid conflicts of interest where practical.

This code applies in repository spaces and when representing the project in public community spaces.
