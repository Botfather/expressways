# Support

Expressways is community-supported alpha software.

- Use GitHub Discussions, if enabled, for usage questions and design discussion.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Before asking for help, review [README.md](README.md) and the [operator runbook](docs/operations/runbook.md). Remove tokens, provider keys, personal data, absolute home-directory paths, and confidential payloads from logs or support bundles before sharing them.

There is no guaranteed response time, uptime commitment, or long-term-support release at this stage.
